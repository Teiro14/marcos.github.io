# Currículum web de Marcos

Currículum en varias páginas hecho con HTML, CSS y JavaScript, publicado con GitHub Pages.

## Páginas
- `index.html` — presentación y habilidades
- `formacion.html` — estudios e idiomas
- `proyectos.html` — proyectos con filtro por categoría
- `contacto.html` — datos de contacto y formulario
- `404.html` — página de error personalizada

## Funcionalidades JavaScript
- Tema claro/oscuro que se recuerda entre páginas
- Menú desplegable en móvil
- Efecto de máquina de escribir en la portada
- Filtro de proyectos por categoría
- Barras de idiomas y tarjetas animadas
- Validación del formulario de contacto

## Estructura
